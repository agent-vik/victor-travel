# Victor Travel

Travel guide portal for Victor42 — Chinese & English itineraries with Word downloads, plus blank itinerary templates.

[Live](https://travel.victor42.work)

## Tech

Static HTML/CSS/JS generated by Python (`scripts/generate_site.py`). Guide content in Markdown; Word docs generated with python-docx. Dependencies in `requirements.txt` (install into a venv).
