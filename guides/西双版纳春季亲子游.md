## 行程

**时间：3月xx日-3月xx日（6天5晚）**  
跨市交通：飞机往返（去程 14:35-18:35；回程 15:30-20:10）。  
市内交通：市区打车；市郊租车/包车。  
住宿：景洪恩季酒店，马路斜对面就是爱琴海购物中心，靠近老城区市中心，到市内各景点打车10分钟左右，到机场打车20分钟。

### D1（3月xx日）出发

杭州萧山(14:35) - 景洪嘎洒(18:35)

- [x] 选座
- [ ] 值机

机场打车到酒店入住，酒店附近自由活动。

### D2（3月xx日）

**景点：原始森林公园(4小时) - 告庄西双景(2小时)**

- [x] 原始森林公园

打车到原始森林公园，景区内或周边用餐。出来后优先打车前往告庄，参观大金塔，逛星光夜市。如果打车困难，坐公交30分钟也可到达。在告庄晚餐后打车回酒店。

### D3（3月xx日）

**景点：曼丢古寨(1.5小时) - 般若寺(0.5小时) - 曼听公园(2小时) - 总佛寺(1小时)**

- [x] 包车
- [ ] 曼听公园

打车去曼丢古寨，散步体验原生态氛围，在古寨里午餐。打车去般若寺参观打卡，如时间紧张可略过。再打车到曼听公园，游玩后凭门票可以连着参观总佛寺。结束后在附近或回酒店周边晚餐，酒店不远，1公里左右，可以步行。

### D4（3月xx日）

**景点：野象谷(全天)**

- [x] 包车
- [x] 野象谷
- [x] 雨林牧象

包车到野象谷，在景区内午餐，游玩一整天。野象谷内有象餐体验，在大象附近用餐，以大象的食物为主，可能需要预定。结束后乘车回酒店附近晚餐。

雨林牧象11:20要到大象科普园签到处。
南门可能不能停车，所以最好再早一个小时到景区。
雨林牧象和景区门票是分开的，都要取票。
如果下过雨，要在景区买雨鞋。

### D5（3月xx日）

**景点：热带花卉园(3小时) - 澜沧江滨江步道(2小时)**

- [ ] 热带花卉园

酒店附近吃个早午餐，打车到热带花卉园。出来后打车去澜沧江滨江步道，白象沙滩玩沙，在周边晚餐。打车回酒店。

### D6（3月xx日）返程

景洪嘎洒(15:30) - 杭州萧山(20:10)

- [x] 选座
- [ ] 值机

**景点：景洪市政府周边Citywalk(2小时)**

退房后去附近的景洪市政府周边Citywalk，14:00前打车回酒店拿行李，打车去机场。

- 3月底当地气温20-35度，夏装+防晒衣足够。
