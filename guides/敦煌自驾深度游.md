## 行程

**时间：4月xx日-4月xx日（5天4晚）**  
交通：租车出行，敦煌莫高机场离市区20分钟车程，租车还车都在机场。  
住宿：全程住在敦煌市内，敦煌博汇文华酒店，距离敦煌沙洲夜市200m。

### D1 出发

萧山机场(06:35) - 莫高机场(12:30)

**景点：敦煌博物馆(2小时)**

- [x] 敦煌博物馆预约

机场租车去酒店放行李，酒店附近午餐，下午逛博物馆。时间有多可以去博物馆附近的白马塔，然后敦煌市区逛逛。晚上去沙洲夜市吃饭。另外买点吃的带车上，第二天西线荒凉，找吃的不容易。

### D2

**景点：西千佛洞(1小时) - 玉门关(2小时) - 阳关(2小时) - 敦煌影视古城(1小时)**

- [ ] 西千佛洞门票
- [x] 玉门关门票
- [x] 阳关门票
- [ ] 敦煌影视古城门票

西线一整天。先去西千佛洞，然后直奔最远的玉门关，在玉门关游客中心午餐。再折返去阳关，最后如果有时间就去影视城。影视城主要是个租衣服拍照的地方，不想去也可以留在阳关看日落，然后直接回市区吃饭。

### D3

**景点：莫高窟(4小时) - 又见敦煌演出(1.5小时)**

- [x] 门票&演出票

车停在游客中心停车场，上午11点半在影院看两场小短片。然后乘景区内的车去洞窟区，我们的A类票有导游带领参观8个随机洞窟，之后都可以在景区内自由活动，晚上8点在莫高窟游客中心看演出。

### D4

**景点：雷音寺(1小时) - 鸣沙山月牙泉(4小时)**

- [x] 鸣沙山月牙泉门票

车停在景区停车场。上午先去雷音寺逛逛，在对面月牙泉小镇午餐。下午进鸣沙山月牙泉，时间情况而定。可以提前返回，或留下来看日落和星空。

### D5 返程

不安排游玩，直接去机场。

莫高机场(12:25) - 中川机场(14:30)  
中川机场(17:50) - 萧山机场(20:40)

## 小提示

- 敦煌与北京有1.5小时的时差，春季日落时间大约晚上8点。
- 敦煌海拔1200左右，不用担心高原反应。
- 注意限速（据说40-80km），很容易超速，导航要全程开。
- 所有景点停车场免费。
- 西线（去玉门关和雅丹）一路上都没有加油站。
- ~~西线据说网络非常差，要用到现金。~~（实地验证发现并不属实）
- 三天内可无限次进入鸣沙山景区。但第一次进去要在大门旁边的机器上刷个脸采集人像。
- 莫高窟有个数字敦煌网站，展示各个窟的详细信息：[https://www.e-dunhuang.com/index.htm](https://www.e-dunhuang.com/index.htm)，另外还有个纪录片《美之全貌》：[https://v.qq.com/x/page/c052998o5ua.html](https://v.qq.com/x/page/c052998o5ua.html)。
- 又见敦煌演出前一小时左右要站着观看，还要根据剧情走动，不是全程坐着的。不能带水和食物。
- 有个微信小程序“博物官”，是敦煌博物馆内部的语音讲解，介绍了许多馆藏文物，有兴趣可以听听。
