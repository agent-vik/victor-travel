### D2（5月xx日）

**景点：秦始皇帝陵博物院(4小时) - 华清宫(2小时) - 永兴坊(1小时)**

- [x] 秦始皇帝陵博物院
- [ ] 华清宫

临潼东线整日，上午出发去兵马俑，优先保证讲解和核心展区，然后转华清宫看唐御汤遗址和西安事变相关区域。不看长恨歌，傍晚回市区永兴坊吃饭逛街。

### D3（5月xx日）

**景点：大唐芙蓉园(5小时)**

- [ ] 装造
- [x] 大唐芙蓉园

大唐芙蓉园装造拍照日，上午不排硬任务，给换装、妆造和路上留余量。下午入园慢逛拍照，傍晚等亮灯和夜景，按还衣时间控制离园节奏。

### D4（5月xx日）

**景点：西安博物院(3小时) - 大雁塔(2小时) - 大唐不夜城(2小时)**

- [x] 西安博物院
- [x] 大雁塔

白天先去西安博物院和小雁塔，下午转到大雁塔片区，晚饭后看大唐不夜城夜景。中间留休息和吃饭缓冲。

### D5（5月xx日）

**景点：西安城墙(3小时) - 广仁寺(1小时) - 化觉巷清真大寺(1小时)**

- [x] 西安城墙
- [ ] 化觉巷清真大寺

老城核心日，城墙作为主景点，从南门/永宁门上城租车，往西骑到西北城角或玉祥门附近下城，接广仁寺；若西北角不能还车，则在西门/安定门下城后前往广仁寺。周六尽量不要太晚登城，若租不到合适自行车，就改为步行一段或乘城墙观光车。化觉巷清真大寺作为机动项，有余力可去。

**景点：大明宫国家遗址公园(2小时)**

- [ ] 大明宫国家遗址公园

返程日大明宫看不完，主要看丹凤门、御道广场和含元殿核心区。算好时间回酒店取行李，下午预留充足时间前往机场。

## 小提示

- 5月中下旬西安白天通常25-30°C、夜间约14-18°C，降水中等（约每月8-10个雨日）；注意防晒，带薄外套和轻便雨具。
- 周末人流集中在城墙、曲江和夜游区域，D5城墙尽量不要太晚登城。
- 大唐芙蓉园不要只白天去，夜景是核心体验；装造日按还衣时间倒推离园。
